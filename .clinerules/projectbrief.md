# Project Brief

## Project Name
`note-next`

## Description
A web-based note‑taking application built with **Next.js**, **TypeScript**, **Tailwind CSS** and **Drizzle ORM**. The app offers i18n support, offline capabilities via a service worker, and authentication using NextAuth.

## Primary Goals
- Provide a fast, responsive UI for creating, editing, and organizing notes.
- Ensure data persistence with a lightweight database layer (SQLite/PostgreSQL).
- Support multiple languages out of the box.
- Allow offline use through a PWA‑style service worker.
- Keep the codebase modular and maintainable.
